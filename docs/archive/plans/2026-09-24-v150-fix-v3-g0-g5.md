# macOS Updates v1.5.0 — Fix Prompt v3 (G0–G5) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the final privacy redaction and security guard (G0) and four minor bug fixes (G1: pkg cask delete hints, G2: App Store verification error handling, G3: Omaha log rotation, G4: npm CLI i18n keys) on `feat/vendor-truth-v1.5`.

**Architecture:** 
- G0: Enforce privacy by redacting inventory diffs from committed review reports, rewriting local unpushed branch history (`main..HEAD`) via `git filter-branch`, sanitizing past references in docs, and adding a static safety test `test_tracked_files_have_no_personal_home_paths` in `tests/test_safety_static.py`.
- G1: Extend `lib/python/brew_casks.py` with `pkg_app_hints(cask)` to extract `.app` names from `uninstall[].delete` stanzas for pkg-based casks in `cask_guard_facts`, leaving `app_targets` and `find_orphan_casks` unchanged.
- G2: Update `update_appstore.sh` verification loop to catch all non-zero exit codes from `ios_apps_pending`.
- G3: Update `scripts/check_vendor_feeds.sh` and `lib/internet_handlers.sh` (`omaha_read_increment`) to support `updater.log.old` upon log rotation.
- G4: Add `L_NPM_DIAGNOSTICS_PATH_FMT` and `L_NPM_LAST_DIAGNOSTICS` across all 7 locale files and use them in `update_npm_cli.sh`.
- G5: Execute full verification and update `docs/reviews/archive/FIX_REPORT_opus55_v2.md`.

**Tech Stack:** Bash 3.2, Python 3.10+, Homebrew JSON schema, Omaha Updater format, standard Unix tools (`tail`, `sed`, `git`).

**Spec:** `docs/reviews/archive/gemini_3.8_flash_opus55_fix_prompt_v3.md`

## Global Constraints

- Apple Silicon (arm64) only, macOS 13–27.
- Bash 3.2 compatibility: no associative arrays (`declare -A`), no `mapfile` or `readarray`, no `${var^^}`.
- Every `update_*.sh` orchestrator must keep `set -o pipefail` and must NOT `set -e`.
- TDD required: write failing test first, verify failure, implement minimal code, verify pass.
- One git commit per task (G0, G1, G2, G3, G4, G5).
- Do not push to remote, do not merge into main.
- No personal user home paths (`/Users/<username>`) in tracked files.
